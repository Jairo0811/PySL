# Política de seguridad

La rama `main` y la versión estable más reciente reciben correcciones de seguridad. Las versiones anteriores pueden dejar de recibir mantenimiento después de publicarse un parche sustituto.

Para reportar una vulnerabilidad, utiliza **Security → Report a vulnerability** en GitHub si la opción está habilitada. No incluyas datos sensibles, credenciales ni pruebas de explotación en issues públicos.

Incluye la versión afectada, sistema operativo, pasos mínimos para reproducir y el impacto observado. El modelo de seguridad y sus límites están documentados en [docs/SEGURIDAD.md](docs/SEGURIDAD.md).
